Ember Pact — an original elemental card battler for the make.fun "Make the best card game" bounty. You face Rook the Ashen Warden, 30 life each: mana grows +1 per turn to 10, you draw and play minions and spells from four elements (Ember, Tide, Gale, Stone — each told apart by colour and a drawn glyph), and playing two cards of one element in a turn triggers Resonance, giving your friendly minions of that element +1 attack. Guard minions must be faced first, minions have summoning sickness, and Rook announces each move before making it, so his choices can be read and countered. Win and loss screens close the duel with stats.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and play with keyboard and mouse. No build step, no network requests, no assets — all art is drawn and all sound is synthesised in code.
